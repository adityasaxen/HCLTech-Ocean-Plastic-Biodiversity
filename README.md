# HCL_Tech_Ocean_Population
# 🌊 Ocean Plastic Density & Marine Biodiversity Analysis

## 📌 Overview

This project was developed as part of my Summer Internship at HCLTech,
Lucknow.

The project focuses on the spatio-temporal analysis of ocean plastic
density and its impact on marine biodiversity in the North Indian Ocean.

The analysis combines data analysis, geospatial analysis, machine learning
and interactive visualization to identify environmental patterns and
associated risk zones.

---

## 🎯 Objectives

- Analyze ocean plastic density across the North Indian Ocean
- Study relationships between environmental variables and biodiversity
- Identify spatial and temporal patterns
- Categorize locations based on environmental risk
- Build interactive visualizations for communicating insights

## 🤖 Machine Learning

### K-Means Clustering

Used K-Means clustering to categorize ocean locations into environmental
risk groups.

### Random Forest

Applied Random Forest to analyze relationships between environmental
variables and the target outcome.

## 🗺️ Geospatial Analysis

GeoPandas was used to create a spatial grid and analyze geographic
patterns across the North Indian Ocean.
